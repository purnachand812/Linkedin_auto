### COMPLETE LINKEDIN POST

Most AI agent frameworks write 400 lines of JSON schema just to call a calculator. Hugging Face built smolagents in roughly 1,000 lines of code by admitting that LLMs write Python better than JSON.

The core idea in huggingface/smolagents is straightforward. Instead of prompting an LLM to emit structured JSON blobs that middleware parses, validates, and routes back to the model, CodeAgent instructs the model to write executable Python snippets.

When an agent needs to search the web, calculate a ratio, and format a response, standard JSON calling requires three roundtrips. In Python, it is three lines of code with real variable assignment:
result = search("quarterly report")
metric = calculate_ratio(result)
print(format_output(metric))

On paper, this eliminates prompt gymnastics and schema validation errors. In practice, substituting JSON for code execution introduces a major security boundary.

Running raw Python generated by an LLM on your host machine is an immediate sandbox liability. If you use CodeAgent, you need Docker or WebAssembly containers to isolate file access and network requests.

Free Apache 2.0 code does not mean free to operate. You still pay inference token costs to whichever provider powers the agent, though lightweight models running locally on Ollama work out of the box.

I haven't tested this on a production multi-agent deployment yet, but for developers tired of over-engineered orchestration wrappers, the repository is worth reading line by line.

Don't give an experimental agent your production credentials. Sandbox it first.

Repo: https://github.com/huggingface/smolagents
