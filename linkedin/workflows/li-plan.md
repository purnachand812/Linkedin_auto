# WORKFLOW: /li-plan (Weekly LinkedIn Content Strategy & Plan)

**Trigger Command:** `/li-plan`  
**Goal:** Generate a balanced 3-post or 5-post weekly content plan distributed across Purna's 4 core content beats.

---

## EXECUTION STEPS

1. **Balance Beats Across the Week:**
   - Post 1: New AI Model Release / Benchmark breakdown.
   - Post 2: Open-Source GitHub Tool / "What It Replaces" audit.
   - Post 3: AI Agent / Autonomous Workflow security & practical evaluation.
2. **Conduct Trending Search:** Search web for recent major GitHub projects and model benchmarks from the past week.
3. **Draft Plan:**
   - Day & Topic.
   - Core question answered ("What does this actually do?").
   - Primary sources to gather.
   - "What It Replaces" target subscription.
