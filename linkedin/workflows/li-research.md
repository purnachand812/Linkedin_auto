# WORKFLOW: /li-research (Technical AI Topic Deep Research)

**Trigger Command:** `/li-research <topic, paper, repo, or technology>`  
**Goal:** Perform an in-depth technical investigation before drafting content.

---

## EXECUTION STEPS

1. **Primary Source Search:** Search for official arXiv technical papers, vendor technical reports, release blogs, and GitHub repositories.
2. **Technical Deconstruction:**
   - Architecture & Innovations (What actually changed at a technical level?).
   - Benchmark Analysis (Who ran the benchmarks? Are they vendor-reported or independent like LMSYS/SWE-bench?).
   - Missing Competitors (Which model baseline was omitted from the comparison charts?).
   - Pricing & Infrastructure (API cost per 1M tokens, VRAM/GPU requirements, rate limits).
3. **Repository Audit (if software/repo):**
   - Check stars, commits, issues, license, Docker requirements, API key dependencies.
4. **Research Brief Output:**
   - Summary of findings.
   - Engineering takeaways.
   - Recommended angle for a LinkedIn post.
